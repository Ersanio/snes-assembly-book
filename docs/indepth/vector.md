# ハードウェアベクタ
ハードウェアベクタとは、ROMで発生する割り込み処理にスーパーファミコンが対応する方法を定義したポインタの集まりです。
各ベクタは2バイトで、バンク`$00`の命令に対応したポインタです。
ベクタは、[スーパーファミコンの2つのモード](../processor/flags.md)、
すなわち「エミュレーションモード」に対応したベクタと「ネイティブモード」に対応したベクタに分類できます。

## ネイティブモードにおけるベクタ
これらのベクターは、スーパーファミコンがネイティブモードで動作している（E=0）場合に参照されます。
|ROMアドレス|ベクタ|備考|
|-|-|-|
|`$00:FFE0`|未使用||
|`$00:FFE2`|未使用||
|`$00:FFE4`|COPベクタ|[オペコードCOP](../indepth/misc.md)で実行される|
|`$00:FFE6`|BRKベクタ|[オペコードBRK](../indepth/misc.md)で実行される|
|`$00:FFE8`|ABORTベクタ|スーパーファミコンでは未使用|
|`$00:FFEA`|NMIベクタ|スーパーファミコンのV-blank割り込みで実行される|
|`$00:FFEC`|未使用||
|`$00:FFEE`|IRQベクタ|スーパーファミコンのH/V-Timer、もしくは外部割り込みで実行される|

## エミュレーションモードにおけるベクタ
これらのベクターは、スーパーファミコンがエミュレーションモードで動作している（E=1）場合に参照されます。
|ROMアドレス|ベクタ|備考|
|-|-|-|
|`$00:FFF0`|未使用||
|`$00:FFF2`|未使用||
|`$00:FFF4`|COPベクタ||
|`$00:FFF6`|未使用||
|`$00:FFF8`|ABORTベクタ|スーパーファミコンでは未使用|
|`$00:FFFA`|NMIベクタ||
|`$00:FFFC`|RESETベクタ|スーパーファミコンのソフトリセットとハードリセットで実行される|
|`$00:FFFE`|IRQ/BRKベクタ|IRQとBRKは[ブレイクフラグ](../processor/flags.md)によって区別できる|


## 設定例
よく使われるベクタを設定するためのコードを紹介します。
このコードは、自分でROMを制作する際に使用できます。
なお、ラベルはバンク`$00`（この設定を記述しているバンクと同じバンク）に記述する必要があります。

```
ORG $00FFE0

; ネイティブモード
dw $FFFF           ; Unused
dw $FFFF           ; Unused
dw $FFFF           ; COP
dw $FFFF           ; BRK
dw $FFFF           ; ABORT
dw NativeNMI       ; NMI
dw $FFFF           ; Unused
dw NativeIRQ       ; IRQ

; エミュレーションモード
dw $FFFF           ; Unused
dw $FFFF           ; Unused
dw $FFFF           ; COP
dw $FFFF           ; Unused
dw $FFFF           ; ABORT
dw $FFFF           ; NMI
dw Reset           ; RESET
dw $FFFF           ; IRQ/BRK
```

自分でROMを制作するプログラマのほとんどは、そのプログラムをネイティブモードで実行させることが多いので、
ほとんどの場合、RESETベクタを除くエミュレーションモードにおけるベクタは設定されません。
加えて、オペコード`BRK`と`COP`は通常使用されることがないため、これらのベクタも無視されることが多いです。
