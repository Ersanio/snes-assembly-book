# レジスタ間転送
以下のような状況を考えてみてください。
あなたはインデックスレジスタであるXレジスタを使用していて、その値に数値$40を足したいとします。
`INX`命令はXレジスタの値を1インクリメントできますが、では#$40を加えるにはどうすればいいでしょうか。
Xレジスタの値を40増やす、という単独のオペコードは存在しませんが、
[算術演算命令](../math/arithmetic.md)を用いることで、アキュムレータの値を$40増やすことは可能です。
この操作を実行するためには、Xレジスタと同じ値をアキュムレータにもロードしなければなりません。
さて、どうすればいいでしょうか。

このような操作を「レジスタ間転送」といって、そのためのオペコードが存在します。
レジスタ間転送のオペコードはいくつもありますが、それらはすべて「T」から始まります。

## アキュムレータ・Xレジスタ・Yレジスタ間の転送
アキュムレータ・Xレジスタ・Yレジスタ間で転送を行うオペコードを紹介します。なお、すべての組み合わせに対応したオペコードが存在します。
|オペコード|正式名称|説明|
|-|-|-|
|**TAX**|Transfer A to X|アキュムレータの数値をXレジスタに転送する|
|**TAY**|Transfer A to Y|アキュムレータの数値をXレジスタに転送する|
|**TXA**|Transfer X to A|Xレジスタの数値をアキュムレータに転送する|
|**TXY**|Transfer X to Y|Xレジスタの数値をYレジスタに転送する|
|**TYA**|Transfer Y to A|Yレジスタの数値をアキュムレータに転送する|
|**TYX**|Transfer Y to X|Yレジスタの数値をXレジスタに転送する|

各オペコードが行う動作はニーモニックの通りです。以下のコードはレジスタ間転送を行う例です。
```
LDA #$45           ; A = $45
LDY #$99           ; Y = $99
TAY                ; A = $45, Y = $45
```
このコードから分かる通り、数値は転送先のレジスタに**コピー**されます。

## 8-bitモードと16-bitモードにおけるレジスタ間転送
転送元レジスタと転送先レジスタがともに16-bitモードであれば、レジスタ間転送は期待通りに動作します。
つまり、以下のように16-bit値が転送されます。

```
LDA #$4512         ; A = $4512
LDY #$9900         ; Y = $9900
TAY                ; A = $4512, Y = $4512
```

もし、8-bitモードのレジスタの値を16-bitモードのレジスタに転送する場合、
スーパーファミコンは転送先レジスタのモードを確認し、転送元レジスタの下位バイトのみを転送します。
以下のコードは、8-bitの値を16-bitモードのアキュムレータに転送する例です。

```
LDA #$4512         ; A = $4512
LDY #$99           ; Y = $0099
TYA                ; A = $4599, Y = $0099
```

反対に、16-bit値を8-bitモードのアキュムレータへ転送する場合は以下のようになります。

```
LDA #$45           ; A = $xx45
LDY #$99AA         ; Y = $99AA
TYA                ; A = $xxAA, Y = $99AA
```
2つ目のコードにおいて、`xx`は任意の8-bit値を表します。
[アキュムレータ・Xレジスタ・Yレジスタの章](../the-basics/register.md)で学んだように、
アキュムレータは実際には常時16-bit幅です。
アキュムレータが8-bitモードでのレジスタ間転送では、その上位バイトが変更されることはありません。
もし、このコードにおいて、アキュムレータが最初に`$1245`を保持していたなら、転送後の結果は`$12AA`になります。
このことはXレジスタとYレジスタには当てはまりません。
これらのレジスタの上位バイトは、16-bitモードを終了した際、即座に$00へクリアされます。

## 汎用レジスタ間の転送
スーパーファミコンの一般的なレジスタに関連したレジスタ間転送命令を紹介します。

|オペコード|正式名称|説明|
|-|-|-|
|**TCD**|Transfer A to direct page register|アキュムレータが16-bitモードであるかどうかに関わらず、アキュムレータの16-bit値をダイレクトページレジスタに転送する|
|**TDC**|Transfer direct page register to A|アキュムレータが16-bitモードであるかどうかに関わらず、ダイレクトページレジスタの16-bit値をアキュムレータに転送する|
|**TCS**|Transfer A to stack pointer register|アキュムレータが16-bitモードであるかどうかに関わらず、アキュムレータの16-bit値をスタックポインタに転送する|
|**TSC**|Transfer stack pointer register to A|アキュムレータが16-bitモードであるかどうかに関わらず、スタックポインタの16-bit値をアキュムレータに転送する|
|**TXS**|Transfer X to stack pointer register|Xレジスタが16-bitモードであるかどうかに関わらず、Xレジスタの16-bit値をスタックポインタに転送する。なお、Xレジスタが8-bitモードのとき、その上位バイトは常に$00である|
|**TSX**|Transfer stack pointer register to X|スタックポインタの16-bit値をXレジスタに転送する。なお、Xレジスタが8-bitモードのとき、その上位バイトは転送後も$00のままである|
